# IMS Health Holdings (ims-health-holdings)
IMS Health Holdings was a leading global information and technology services company providing clients in the healthcare industry with end-to-end solutions before merging with Quintiles in 2016 to form IQVIA. No standalone public API is offered under the IMS Health Holdings brand; current API and data products are available through IQVIA.
